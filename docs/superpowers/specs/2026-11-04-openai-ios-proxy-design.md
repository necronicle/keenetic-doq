# Переключение доменов OpenAI для iOS на 217.60.179.6

## Цель

Направить восемь доменов из присланной пользователем конфигурации на `217.60.179.6`, чтобы проверить этот прокси с приложениями iPhone. Прямая проверка с `curl --resolve` подтвердила установление TLS и HTTP-ответы для всех восьми имён; полный сценарий iOS ещё потребует проверки на устройстве.

## Объём и ограничения

- Для `chatgpt.com`, `auth.openai.com`, `cdn.oaistatic.com`, `ios.chat.openai.com`, `api.openai.com`, `files.oaiusercontent.com` и `oaistatic.com` удалить старые адреса `5.175.161.3` и `5.175.161.40`, оставив только `217.60.179.6`.
- Добавить точное имя `chat.openai.com` с адресом `217.60.179.6`.
- Не менять остальные имена во встроенном hosts-списке и не добавлять wildcard-правила.
- Обновить текущие сведения о количестве имён с 1025 до 1026 и соответствующие тесты; исторические записи планов и CHANGELOG не переписывать.

## Подходы

1. **Выбран: точечная замена восьми доменов.** Минимальная область изменений; остальные сервисы продолжают использовать прежние прокси.
2. **Отклонён: перевод всего встроенного списка.** Один адрес не проверен для остальных сервисов и мог бы нарушить их работу.

## Проверка

Запустить `go test ./...`, проверить загрузку встроенного списка, DNS-ответы всех восьми имён и отсутствие старых адресов именно у этих записей. После установки обновлённого бинарника потребуется перезагрузить hosts-конфигурацию и проверить приложение на iPhone.
